# Contributing Guidelines

Contributions of all kinds are welcome - bug reports, feature ideas, documentation improvements, and pull requests.
Please open an issue before starting major work to ensure alignment.

- Report issues or features here: [ISSUES/FEATURES](https://github.com/SauravDnj/invoice/issues)
- Feature requests and discussions are welcome
- Please follow [guidelines](https://github.com/SauravDnj/invoice/blob/main/CONTRIBUTING.md)
- For agentic/AI-assisted development workflows, see [AGENTS.md](https://github.com/SauravDnj/invoice/blob/main/AGENTS.md)
